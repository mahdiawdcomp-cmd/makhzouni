# الكشف العام اليومي (تلقائي، بدون فتح البرنامج)

ينزّل «الكشف العام» — كشف حساب كل الزبائن — كملف HTML واحد كل يوم،
ويحتفظ بآخر ٣٠ يوم ويمسح الأقدم. يشتغل والبرنامج مسكّر، وبدون أي نافذة.

## ليش السيرفر يولّد الملف مو الجهاز

الملف ينبني بالباك-إند (`customer-statement-html.service.ts`) والسكربت
ينزّله جاهز. السبب: جهاز فيه البرنامج منصّب ما عنده Node ولا `node_modules`،
فما يكدر يبني التقرير أصلاً. ولو انكتب مولّد ثاني بـPowerShell، تصير نسختين
من نفس التقرير تفترقان مع الوقت — وهذا بالضبط اللي صار سابقاً لما وصلت
نسخ الكشف إلى ثلاث تطبيقات مختلفة.

نفس المقطع يستخدمه زر «حفظ الكشف العام» داخل البرنامج، فالملف المؤرشف
والملف اللي تنزّله بيدك متطابقان دائماً.

## وين تنحفظ الأشياء

```
%APPDATA%\com.mazbwoni.mahdi\statements\
├─ الكشف-العام-2026-09-09.html      ← ملف اليوم
├─ statement-status.json            ← آخر نجاح/فشل، عدد الملفات المحفوظة
└─ logs\statement-2026-09-09.log    ← سجل اليوم
```

الملف يفتح بأي متصفح، بدون إنترنت وبدون البرنامج. ما بيه JavaScript
إطلاقاً — الطي والفتح يصير بـ`<details>`، حتى يبقى شغّال بعد سنين.

## التشغيل اليدوي

```bash
npm run statement:daily
```

## التشغيل التلقائي اليومي

```bash
npm run statement:install-task
```

لازم PowerShell **بصلاحية مدير** (Run as Administrator). يسجّل مهمة
`MakhzouniDailyStatement` تشتغل كل يوم ٣:٣٠ فجراً — بعد نسخة الباكاب
اليومية ٣:٠٠ بنص ساعة، حتى الاثنتان ما تتزاحمان على نفس الـAPI.

المهمة مضبوطة `-StartWhenAvailable`، يعني إذا كان الجهاز مطفي بذاك الوقت
تشتغل أول ما يفتح.

للتجربة فوراً بدون انتظار:

```bash
powershell -Command "Start-ScheduledTask -TaskName 'MakhzouniDailyStatement'"
```

## السر

يقرأ نفس المتغير مال الباكاب: `MAKHZOUNI_BACKUP_SECRET`، ولازم يكون
مضبوط على مستوى **المستخدم** (`setx`) مو الجلسة — لأن المهمة تشتغل بـS4U
وتقرأ متغيرات البيئة من ملف المستخدم:

```bash
setx MAKHZOUNI_BACKUP_SECRET "نفس قيمة BACKUP_SECRET بالسيرفر"
```

السر يُرسل بترويسة `X-Backup-Secret` مو بالرابط، حتى ما ينحط بسجلات
الوصول على الطريق.

## خيارات

| الخيار | الافتراضي | شنو يسوي |
|---|---|---|
| `-RetentionCount` | `30` | كم ملف يحتفظ بيه |
| `-CustomerFilter` | `all` | `all` / `withBalance` / `inactive` |
| `-TimeZone` | فارغ | المنطقة الزمنية اللي تنطبع بيها التواريخ. فارغ = تُشتق من فرق توقيت الجهاز |
| `-Time` (بالمثبّت) | `03:30` | وقت التشغيل اليومي |

**عن المنطقة الزمنية:** السيرفر يشتغل بتوقيت UTC. بدونها كانت فاتورة
مسائية تنطبع بتاريخ اليوم التالي. الاشتقاق التلقائي مضبوط للمناطق اللي ما
عندها توقيت صيفي (العراق منها)؛ على جهاز بمنطقة عندها توقيت صيفي مرّر
`-TimeZone` صراحةً.

## الأمان عند الفشل

- خطأ ٤٠١/٤٠٣ يوقف فوراً برسالة واضحة، بدون إعادة محاولة — السر غلط، والإعادة
  بس تأخّر اكتشاف المشكلة. باقي الأخطاء تُعاد ٣ مرات بتباعد.
- الملف ينزل لملف مؤقت وينفحص (حجم + علامة عنوان التقرير) **قبل** ما يحل محل
  أي شي.
- إذا فشل اليوم: ملف أمس يبقى، والحذف التلقائي **ما يشتغل** — يوم فاشل ما
  يجوز ياكل نسخة قديمة.
