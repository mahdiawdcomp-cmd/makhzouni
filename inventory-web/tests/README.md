# اختبارات المتصفح لشاشة المندوب

## التجهيز لمرة واحدة على كل جهاز

```bash
npm run build
npm run test:browser:setup
```

`playwright` موجود كـ**devDependency**، لكن متصفح Chromium **لا يُنزّل مع `npm install`** —
حجمه مئات الميگابايت وأكثر من يعمل على هذا المستودع لا يحتاجه. أمر التجهيز أعلاه
يُنزّله مرة واحدة (يكافئ `npx playwright install chromium`).

على Linux أو داخل CI يلزم تنزيل مكتبات النظام أيضاً:

```bash
npx playwright install --with-deps chromium
```

## التشغيل

```bash
npm run test:browser
```

الاختبارات تعمل على **النسخة المبنية** (`dist`)، فأي تعديل على الكود يحتاج
`npm run build` قبل إعادة التشغيل.

## إذا Chromium غير مثبت

الاختبار يفشل برسالة سطر واحد تقول ماذا تشغّل، **ولا يترك أي عملية خلفه**:
سيرفر البيانات الوهمية يُسجّل إيقافه لحظة جاهزيته، قبل تشغيل المتصفح.

## المنافذ

كل اختبار يشغّل سيرفر بيانات وهمية على **منفذ يختاره النظام** (`FIXTURE_PORT=0`)،
فلا يتعارض اختبار مع آخر، ولا تحجز عملية قديمة منفذاً ثابتاً. لا يوجد أي منفذ
مكتوب يدوياً.

## ماذا تغطي

| الاختبار | القياس | ما يثبته |
|---|---|---|
| الطلب المعلّق | 390×844 | قطع الشبكة فعلياً بـ`context.setOffline()`، ثم reload، ثم رجوع الاتصال: التنبيه يظهر، ولا إرسال تلقائي، وإعادة التحقق تُنتج **طلباً واحداً** بنفس المفتاح |
| مقاسات الآيباد | 1024×768 | لا تمرير أفقي، وكل أزرار الشاشة ≥ 44px، في ثلاث تبويبات |

لا قاعدة بيانات، ولا باكند، ولا بيانات إنتاج، ولا أي طلب حقيقي.

## CI

لا يوجد `.github/workflows` في هذا المستودع اليوم. إذا أُضيف، خطوة اختبار
المتصفح **فقط** تحتاج:

```yaml
      - run: npm ci
      - run: npm run build
      - run: npx playwright install --with-deps chromium
      - run: npm run test:browser
```

لا تضِف تنزيل المتصفح إلى `postinstall` ولا إلى خطوة تجهيز عامة.
