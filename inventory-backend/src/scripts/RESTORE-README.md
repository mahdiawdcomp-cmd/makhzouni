# اختبار استرجاع النسخة الاحتياطية

## ليش موجود

النسخ اليومية كانت تُنتج ملفات **ما عندها أي طريق للاسترجاع**. سكربتات
`verify-backup*.ps1` تفتح الملف المضغوط وتتأكد أن الـ JSON سليم — وهذا يثبت
أن الملف موجود، لا أنه قابل للاسترجاع.

أول استرجاع فعلي جرى بتاريخ 2026-09-13 على نسخة الإنتاج الحقيقية
`makhzouni-online-2026-09-12-12-01.zip` داخل قاعدة معزولة محلية، وكشف
ثلاث مشاكل ما كانت تظهر بأي فحص نظري.

## شلون تشتغل

```bash
npm run backup:restore -- --file "C:/…/makhzouni-online-YYYY-MM-DD.zip" --target "postgresql://postgres:pass@localhost:5432/restore_test" --wipe
```

قبلها القاعدة الهدف تحتاج:

```bash
npx prisma migrate deploy
```

ثم **إقلاع الخادم مرة واحدة عليها** — لأن مجموعة أعمدة تُضاف عند الإقلاع لا
عبر ملفات الترحيل. السكربت يفحص هذا ويوقف برسالة واضحة إذا كانت ناقصة.

## الحواجز

- عنوان القاعدة الهدف يُمرَّر يدوياً بـ `--target` ولا يُقرأ من البيئة أبداً،
  حتى لا يصير أن ملف بيئة شارد يوجّه الاسترجاع على محل شغّال.
- الهدف لازم يكون محلياً، وإلا يحتاج `--i-know-this-is-remote`.
- `--wipe` مرفوض تماماً على أي قاعدة غير محلية.
- مصدر النسخة لا يُكتب عليه إطلاقاً.

## اللي كشفه أول اختبار

1. **المستخدمون ما ينسترجعون.** النسخة تستثني كلمة المرور المشفّرة عمداً،
   فالاسترجاع كان يتوقف عند أول جدول. الحل: الحسابات ترجع **مقفلة** بقيمة
   لا تطابق أي كلمة مرور — الأدوار والصلاحيات ومراجع الفواتير تبقى سليمة،
   والمدير يضبط كلمات مرور جديدة بعد الاسترجاع.
2. **ترتيب الإدخال.** مرتجع المبيعات يشير للفاتورة الأصلية، وحركة المخزون
   تشير للتحويل والتالف. التصدير مرتّب من الأحدث للأقدم فكانت المراجع تنكسر.
   الحل: الإدخال من الأقدم للأحدث، والتحويلات والتوالف قبل حركات المخزون.
3. **الأهم: النسخة ما كانت تحفظ أرصدة المخازن ولا العدّادات.** الكتب رجعت
   كاملة — ٢٩٤١ فاتورة فعّالة و٧٣٥ مليون مبيعات و١٣٠ زبون بديون مجموعها ٢٨
   مليون — بينما **٩٠٩ مادة رجعت برصيد صفر**، والعدّادات صفر يعني ترقيم
   الفواتير يبدأ من جديد ويصطدم بالفواتير المسترجعة.

النسخة صارت إصدار `2.2` وتشمل الجداول الحرجة: أرصدة المخازن، العدّادات،
التوالف، الموافقات، الجرد، الجرد الدوري، وسجلات المندوب. ملف الإصدار `2.1`
وما قبله يسترجع الحسابات فقط — أرصدة المخزون فيه مفقودة نهائياً.

## اللي ما زال خارج النسخة

مذكور داخل كل ملف نسخة بحقل `meta.excludes`: الكتلوك بكل جداوله، والمراسلات
(واتساب، تيليگرام، الحملات، التنبيهات)، وإنستغرام، وملفات الوسائط، وكلمات
المرور. هذي ما تمنع استرجاع المحل والحسابات، بس لازم تعرف أنها ما ترجع.
